KDE Plasma 6 HDR Toggle
A simple, robust script to toggle HDR and Wide Color Gamut (WCG) on KDE Plasma 6 (Wayland). Optimized for high-end setups like the LG C3 OLED and AMD RX 9000 series GPUs.

Features:
Auto-detection: Automatically finds your active display output name.

WCG Support: Ensures colors look correct by enabling Wide Color Gamut with HDR.

OS Notifications: Provides desktop feedback when switching modes.

Installation:
Save the script HDR-toggle.sh to your home folder.

Make it executable: chmod +x ~/HDR-toggle.sh

Set up the Keyboard Shortcut:

Open System Settings -> Keyboard -> Shortcuts.

Select Commands and click + Add New.

Name: Toggle HDR

Command: /home/dimid/HDR-toggle.sh

Shortcut: Meta+Alt+B

Verify: Press the shortcut and look for the HDR logo on your LG C3 or similar TV/monitor.
